# ADR 0234: 「焼き込んだ数字は腐る」の道具・生成物版を `AGENTS.md` へ置く — ⛔ 射程だけを広げず、**線**と**対象外**を同時に書く

- **状態**: 採用 (2026-09-18)
- **日付**: 2026-09-18

**⚠ 各主張の出所を分ける**（ADR 0132 / 0137 / 0179 / 0199 / 0200 / 0211 / 0212 の体裁を踏む）。

- **【現物】** — この repo のコード・文書を書き手が読んで確かめた。
- **【実測】** — この書き手が自分の手で `git`/`vitest` 等を走らせて確かめた。
- **【受】** — 依頼元（マネージャー）からの報告として受け取り、再導出していない。

## 文脈

**[ADR 0223](./0223-cross-cutting-disciplines-extracted-from-the-adr-corpus.md) は、ADR 211本の母集合から「繰り返し採られているのに入口の文書に書かれていない規律」を10本抽出した。**その決定9 がこれである【現物・逐語】:

> **一般形**: **`main` が動けば変わる数（件数・行番号・版・tag・sha）を、道具や文書に写さない。**⟹ **唯一の出所をその場で引くか、指すだけにする。**⟹ **直せないものは、代わりに「どこまで数えたか」の鮮度を名乗らせる。**

**⛔ そして ADR 0223 は、成文化の場所を自分では決めなかった**【現物・逐語、「⛔ 成文化の場所 —— **未決のまま残す**」節】:

> **どこへ置くかで読者が変わる。**`AGENTS.md` は人もエージェントも読む。`docs/autonomy.md` は「オーナーに逐一確認せずに進める担い手」向けだと自ら宣言している。⟹ **決定2・3・5・9 は *道具を作る側* への規律であり、そのどちらの宛先とも一致しない。**⭐ **3本目の宛先が要るのかどうかも、この ADR は決めない。**

**その未決を [Issue #505](https://github.com/takecchi/mnemora/issues/505) が引き取り、6つの決定（2/3/5/6/9/10）を1本ずつ判断することにした。この ADR は、そのうち決定9 だけに答える。**

⚠ **【受】この ADR の判断そのものは、Issue #505 のコメントに先に置かれている**（逐語「✅ **判定: 決定9 — yes（`AGENTS.md` の射程を道具・生成物まで広げる）。ただし「線」と「対象外」を*同時に*書くこと**」。⛔ **そのコメントは「クローン miku（自動化された担い手）による判定である。オーナー本人の判定ではない」と自ら名乗っている**）。**この ADR が足すのは、その判断を記録の形にすることと、下の「確かめたこと」である。**

## ⭐ なぜ入口へ置くのか — **射程が書かれていないせいで、実際に誤った判定が出ている**

**【現物】`AGENTS.md` には、同じ規律が既に2つ在る。⛔ どちらも道具・生成物を覆っていない。**

| 在る版 | 対象 |
|---|---|
| 「⚠ ここに北極星の要約を置かない」（逐語「**複製した瞬間から、正文と要約はずれ始める。**」） | **文書の複製** |
| トレーラ節（逐語「**⟹ 母数（総コミット数）は main が動けば変わる。この数字を引くときは、必ずどの SHA で見たかを添えること。**」） | **人が書く報告に SHA を添えること** |

⟹ 🔴 **「出荷する道具・生成物そのものが数字を持つ」場面は、どちらにも入っていない。**そして ADR 0223 決定9 が「独立に採った」として挙げる7本（0214 / 0070 / 0082 / 0084 / 0127 / 0137 / 0213）は、**まさにそちら側である**【現物】。

**そして、書かれていないことの害は仮定ではない。**⚠ **【受】** [Issue #403](https://github.com/takecchi/mnemora/issues/403) で「基準値を実測で更新する案は ADR 0223 決定9 に反する」として一度却下され、**その却下が後に撤回された**（Issue #505 の判定コメントが、撤回した本人の申告として記録している）。⛔ **この経緯そのものは、書き手が該当コメントを開いて確かめたものであり、当事者に確認したわけではない。**

## 🔴 決定

### 決定1. `AGENTS.md`「作業のときの決まり」に「⚠ 数を、道具と生成物に焼き込まない」を新設する

**書くのは3つ**: (1) 一般形（`main` が動けば変わる数を道具・生成物に写さない） (2) **線** (3) **対象外**。

⭐ **ADR 0223 決定9 が挙げる7本の一覧は、`AGENTS.md` へ写さない。ADR 0223 を指すだけにする。**⟹ **この決定自身の自己適用である**（一覧は ADR が増えれば動く）。

### 決定2. ⭐ **線は「`main` が動くと変わるか」である** — これを一緒に書く

**⛔ 射程だけを広げると、正しい焼き込みまで飲み込む。**

**【現物】ADR 0223 決定9 自身が反例を持っている（逐語）:**

> **反例・例外**【現物】: ADR 0212 は **`36MB` / `42MB` という数字を歯で縛っている**。⟹ **焼き込んでよい数字も在る。線は「`main` が動くと変わるか」である**——モデルの重みのサイズは `main` では動かない。

⟹ **この線を書かずに射程だけ広げると、[ADR 0212](./0212-local-embedding-size-noun-correspondence-tooth.md) が正しく置いた歯が、規約違反になってしまう。**

⭐ **【実測 2026-09-18 JST】この節を書くときに、その歯が実際に噛んだ。**
`AGENTS.md` へ反例を書く際、ADR 0223 決定9 の逐語をそのまま写した（`36MB` / `42MB` と「モデルの重み」）ところ、`scripts/__tests__/local-embedding-size-noun-correspondence.test.mjs` が
**`AGENTS.md:270` と `CLAUDE.md:270` の2件**を「`42MB` が『重み』文脈に付いている（期待値 `36MB`）」として赤にした。
⟹ ⭐ **入口へ数字を写した瞬間に、既存の歯が捕まえた。**⛔ **対処として数字を直すのではなく、`AGENTS.md` からは数字を落として ADR 0212 と歯を指すだけにした**——**この ADR の決定1 自身の適用である。**
⚠ **ADR 本文（`docs/decisions/**`）はこの歯の対象外である**【現物】（同テストの逐語「⛔ **ADR (`docs/decisions/**`) は対象外。** このリポジトリは ADR 本文を書き換えない」）。⟹ **この ADR が上で引いている逐語は、意図して残している。**

### 決定3. 🔴 **対象外は「実測して repo にコミットした基準値」である** — これも一緒に書く

**CI の実測 artifact をそのまま基準値としてコミットしたものは、この規律の対象ではない。⭐ それは複製ではなく、測った記録そのものだからである。**

**【現物】repo は逐語で、基準値を手で書かないこと・CI の artifact をそのままコミットすることを決めている:**

| 出所 | 逐語 |
|---|---|
| [ADR 0119](./0119-archive-sweep-cost-bench.md) 決定6 | 「**実測せずに数値を書けば、それは捏造である。**」 |
| [ADR 0121](./0121-bench-baselines-from-ci-artifacts.md) 決定1 | 「**手で数値を書いた欄は無い。**両ファイルとも、ダウンロードした JSON をプログラムで…」 |
| [ADR 0133](./0133-compare-baseline-and-gate.md) 決定1 | 「CI の artifact をそのまま基準値の本体にする(手で数値を書いた欄は無い)」 |
| [examples/chat/README.md](../../examples/chat/README.md) | 「値が意図して動いたときは人が更新する——⭐ **その手間は目的である**」 |

**⭐ 見分ける問いは1つだけ書く**: **その数は、どこか別の場所に在る正本の*写し*か。それとも、それ自体が*測った記録*か。**⟹ **写しなら指す。記録なら残す。**

### 決定4. ⛔ **この ADR では歯を作らない**

**個別インスタンスの ISSUE が既に4本在る**【現物】: [#433](https://github.com/takecchi/mnemora/issues/433)（CHANGELOG 未リリース節）/ [#455](https://github.com/takecchi/mnemora/issues/455)（local-embedding のサイズ）/ [#512](https://github.com/takecchi/mnemora/issues/512)（ソースの行番号 122箇所）/ [#518](https://github.com/takecchi/mnemora/issues/518)（`Runtime` のメソッド数 3箇所）。

⛔ **そのどれについても、この ADR は歯を作らない。**⚠ **#512 / #518 が逐語で挙げている保留の理由がそのまま当たる**（逐語「**#505 の決定9 が成文化される前に歯を作ると、歯が「正しい焼き込み」まで捕まえる**」）。⟹ **この ADR は、その「成文化」のほうを済ませる。歯はその後の別の判断である。**

⚠ **そして、成文化が済んでも歯が自動的に正当化されるわけではない**——[ADR 0223](./0223-cross-cutting-disciplines-extracted-from-the-adr-corpus.md) 決定3（逐語「**偽陽性率に上限を置けない検査は、門にしない**」）が別に当たる。**線（決定2）と対象外（決定3）を機械が判定できるかは、この ADR では測っていない。**

## 採らなかった案

| **`docs/autonomy.md` へ置く** | 【現物】同文書は冒頭で「オーナーに逐一確認せずに作業を進めるエージェントのためのもの」と宣言している。⟹ **この規律は、人が対話で書く道具にも当たる。**宛先が狭すぎる |

| **一般形だけを書き、線と対象外は書かない** | 🔴 **これが Issue #403 で実際に起きた誤りの形である。**射程だけが伝わると、正しい焼き込み（ADR 0212 の歯、CI artifact の基準値）まで違反として扱われる |
| **6つの決定をまとめて1本の PR で成文化する** | ⛔ Issue #505 自身が「**1本ずつ判断する**」と題に書いている。⚠ そして決定9 以外は、まだ判定が出ていない |
| **ADR を書かず、`AGENTS.md` の変更だけ出す** | ⛔ 落ちない。**ADR 0223 が明示的に「未決のまま残す」と書いた論点に答えている**——`AGENTS.md` の diff だけでは、なぜ `docs/autonomy.md` でも新設文書でもないのかが残らない |

## 引き受けた負債

- **残る5つ（ADR 0223 決定2 / 3 / 5 / 6 / 10）の宛先は、まだ決まっていない。**⟹ この ADR は決定9 の1本だけを動かしており、**Issue #505 は閉じない。**
- ⛔ **`AGENTS.md` に置いたからといって、守られるとは限らない。**⚠ **ADR 0223 自身が同じ留保を書いている**【現物・逐語】: 「⛔ **「書けば守られる」とは、この ADR は主張しない。**」——同 ADR は、**ADR 0213 決定5 が書かれていたうえで PR #481 が外した**という実例まで挙げている。
- **線（`main` が動くと変わるか）は、判定に読み手の知識を要する。**たとえば「モデルの重みのサイズ」が `main` で動かないことは、`main` を見ても分からない（モデルを差し替える PR が来れば動く）。⟹ **この線は機械的ではない。**

## これが覆るとしたら

- **残る5つの判定が出そろい、そのうち複数が「`AGENTS.md` では宛先が合わない」となったとき。**⟹ ADR 0223 が残した「3本目の宛先」を、まとめて作り直す判断になりうる。**その場合もこの ADR の本文は書き換えず、追記で訂正する**（`docs/decisions/README.md` の規約）。
- **「実測してコミットした基準値」の運用そのものが変わったとき**（たとえば CI が基準値を自動更新するようになったとき）。⟹ 決定3 の対象外は、その前提（ADR 0119 決定6 / 0121 決定1 / 0133 決定1）に乗っている。
- **線（`main` が動くと変わるか）で切れない例が出たとき。**⟹ 決定2 は ADR 0212 の1例だけを反例として持っており、**2例目で崩れる可能性を排していない。**

- ⛔ **「`AGENTS.md` に書かれていない」の判定は、Issue #505 のコメントが `grep` で行ったものを引き継いでいる。**⚠ **`grep` が網羅であることは示していない**（ADR 0223 決定4 の反例が自分に当たる）。書き手は `AGENTS.md` を通読して裏づけたが、`docs/autonomy.md` の全文は通読していない。
- ⛔ **線と対象外が、機械で判定できるかは測っていない。**⟹ 歯を作る判断（決定4）の材料は、この ADR には無い。
- ⛔ **既存の道具・生成物に、この規律に反する焼き込みが何件在るかを数えていない。**⟹ 母集合は #433 / #455 / #512 / #518 の4本が部分的に持っているだけである。
