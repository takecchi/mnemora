**文書と TSDoc のコメントだけの変更**で、振る舞い・コード・テストは変えない。[ADR 0576](./0576-doc-code-drift-sweep-core-public-tsdoc.md) などの「文書とコードのずれを横に掃く」PR と同じ形。[ADR 0641](./0641-merged-0930-docs-recheck-teeth.md) が「本文の直しが要る」として外した #1503 の食い違いも、この PR で扱う。

## 経緯

H 群の PR は文書だけの PR で、マージの後に、別の PR・ADR（0431・0442・0502・0456・0635 など）や v1.2.0 の出荷で、文書の記述が実装とずれた【現物】。確かめ直しは、各 PR の約束を今の main に当て直して読み比べた。食い違いはどれも軽い。

## 決定【判断】

1. **日付の付いた節の本文は書き換えない。** 食い違いがその中にあるときは、節の後に「（2026-10-06 訂正）」で始まる段落を足す。日付の付いていない生きた文書（README の説明・TSDoc・`conformance.md` の地の文など）は、その場で直す。
2. **採用済みの ADR の本文は変えない。** ADR 0413・0228・0431・0442 には、末尾に追記だけを足す（[README](./README.md) の作法）。
3. 新しい決定を足す PR ではないので、`CHANGELOG.md` の `[1.3.0]` の Fixed に、公開 TSDoc を直したことの1項目だけを足す（ADR 0576 と同じ）。

## 直さなかったもの【判断】

- `scripts/adr-renumber.mjs`・`scripts/adr-renumber-lib.mjs` の説明コメントが「マージする側」と書いていること（#1503 の指摘）。スクリプトのコメントで、この PR の範囲（文書と TSDoc）の外。材料として残す。
- ADR 0228 以外の「マージする側が再生成する」を本文に持つ ADR（0158・0179・0273・0283・0379）への追記。ADR 0228 の追記に一覧にした。
- ADR 0431 の測定値そのものの再現（生データとスクリプトが repo に無い）。表の算術だけを確かめた。
- ADR 0413 の「100万行で温 約30 ms」と ADR 0412 の「409 ms は許容外」の線を揃えること。判断の食い違いであり、この PR では決めない（ADR 0413 の追記に書いた）。

## 引き受けた負債

- 文書の食い違いを、今回も人の読み比べで見つけた。これを機械で縛る歯は足していない（機械は「検出」まで、`AGENTS.md`）。同じ形の食い違いは、後の出荷でまた起きうる。
- `ctx.ts` の「2026-09-30 訂正」の括弧は、TSDoc なのでその場で直した。日付の付いた本文に手を入れた例外になる。

## これが覆るとしたら

- 文書の食い違いを検出する歯（例: README の `note` の記述と `matchesTruncated`、`ctx.ts` の列挙と `ObserveInputSchema` のずれ）の偽陽性率に上限が置けると実測できたとき。
