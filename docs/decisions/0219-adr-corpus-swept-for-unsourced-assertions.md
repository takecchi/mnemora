## 見つかったもの

### 1. 🔴 **残った17件のうち13件（3/4超）が「外部の挙動」についての主張だった**

| 何についての主張か | 件数 | 例 |
|---|---|---|
| **外部の挙動・外部の出来事** | **13** | PostgreSQL の行ロック／advisory lock のキー空間／`FOR UPDATE SKIP LOCKED` の解放タイミング（ADR 0017 / 0030 / 0032）、npm の `EUNSUPPORTEDPROTOCOL`・semver の `^0.0.x`（ADR 0060）、Prisma Studio・Prisma 7 GA・Drizzle 公式ガイド（ADR 0001）、GitHub の cache API（ADR 0141）、BullMQ の保守状況（ADR 0005）、「一部のベクトル DB 製品」（ADR 0004）、`virchamate` の承認範囲（ADR 0093） |
| **自分の過去の出来事で、追跡子が無い** | **2** | ADR 0019 §5c／ADR 0034 の「後続 PR」 |
| **他の担い手の作業状況** | **2** | ADR 0042／ADR 0045 |

🔴 **これが本 ADR のいちばんの発見である。**
**この repo のブラケット規律は「自分が測ったこと」には極めてよく効いている**（落とした 154件のうち 68件が名乗り済み）。
⛔ **効いていないのは「外から受け取った知識」の側である。**

⭐ **なぜそうなるかは、残った13件の姿が教えている。**
「`FOR UPDATE SKIP LOCKED` の行ロックはコミット時に解放される」も
「`^0.0.1` は patch すら拾わない」も、**おそらく正しい。**
**正しいからこそ「よく知られた事実」に見え、「これは自分で測ったか？」という反射が起きない。**
⟹ ⛔ **「測ったか」を問う反射は、自分の実測にしか向いていなかった。**

⚠ **本 ADR は、残った17件が**偽**だとは1件も言っていない。**
🔴 **言っているのは「この repo に裏づけが無い」だけである。**

### 2. 🔴 **ADR 0217 の逆——「複製で名乗りが *増える*」形が在った**

ADR 0217 が見つけたのは **「複製先で名乗りが落ちる」** 形だった。**逆が在る。**

**【現物】`docs/release-v1.md`:**

> **なぜ `pnpm` でなければならないか**: `npm pack` は `workspace:*`/`workspace:^` を
> 置換せず、素の consumer の `npm install` が `EUNSUPPORTEDPROTOCOL` で落ちる
> （**実測**。ADR 0060「2. `npm pack` は `workspace:*` を置換しない。…」。**【読んで確かめた】**）。

**【現物】ところが ADR 0060 が実測したのは、tarball 内の `package/package.json` の `dependencies` 欄の逐語比較である**
（`"workspace:*"` のまま残るか、`"0.0.0"` に置換されるか）。
⛔ **その tarball を実際に install して `EUNSUPPORTEDPROTOCOL` が出ることを確かめた記録は、ADR 0060 のどこにも無い。**

🔴 **⟹ 下流の運用手順書が、上流が測っていない半分にまで「実測」のラベルを広げている。**

⚠ **`【読んで確かめた】` の二義性が効いている**——これは
**「ADR 0060 にそう書いてあることを読んで確かめた」**であって
**「install が落ちることを確かめた」ではない。** ⛔ **読む人には区別がつかない。**

🔴 **落ちた名乗りより、増えた名乗りのほうが危ない。**
**名乗りが落ちた主張は「根拠が無さそう」に見える。名乗りが増えた主張は「根拠が在る」ように見える。**
⟹ **`docs/release-v1.md` は、リリース当日に人が手順として読む文書である。**

### 3. ⭐ **執筆の事故は、複製の事故より悪いことがある**

ADR 0217 は「**同じ commit か / 別の commit か**」で執筆の事故と複製の事故を分ける道具を置いた。**使った。**

**【現物】**「partial index は離散値・低カーディナリティのフィルタに**公式に推奨されている**」は**3箇所に在り、
3箇所とも同じ commit `1cf6a60`（PR #1、設計フェーズの最初の commit）で入っている** ⟹ **執筆の事故である。**

🔴 **ところが、同時に書かれた3つの「誰の公式か」がずれている:**

| 場所 | 誰の公式か |
|---|---|
| ADR 0004 | 「**公式に**推奨されている」（**主体が書かれていない**） |
| `docs/memory-model.md` | 「**PostgreSQL 公式**の推奨」 |
| `docs/recall.md` | 「**pgvector 公式**の推奨」 |

⟹ ⭐ **1回の執筆で3箇所に書いたのに、3つが互いに違うことを言っている。どれが正文か分からない。**
⛔ **「同じ commit だから執筆の事故、だから軽い」ではない。**
**複製の事故なら少なくとも元の1つは正しい。執筆の事故は、最初から3つとも別々にずれていることがある。**

## 決定

### 1. **13件は、元の記述を消さず「名乗りを戻す追記」で直す**

ADR 0217 決定1 / ADR 0218 決定1 を引き継ぐ。**ADR の本文は書き換えず、冒頭に追記ブロックを足す。**
⛔ **「だから使うな」「だから直せ」とは書かない。** ⭐ **「この repo に裏づける実測は無い」と書くだけである。**

`docs/release-v1.md` の1件は **「⚠ 2026-09-17 訂正」**として、
**元の行を消さずに「ADR 0060 が実測したのはどこまでか」の切り分けを添えた。**

### 2. ⛔ **3件は直さない**

| 件 | 直さない理由 |
|---|---|
| **ADR 0034** の「後続 PR で変異を撃った」 | **PR 番号・sha が無く追跡不能。** ⛔ **真偽を判断する材料が無い**——実在する PR を指すのか記述の誤りかを切り分けられない。**オーナーの確認が先である。** |
| **ADR 0042 / ADR 0045** の「別のマネージャーが作業中」「別の委譲が触っている」 | 🔴 **他の担い手の作業状況は、この repo の中身からは原理的に検証できない。** かつ **当時の内部調整の記録**であり、**書き換えると当時の実態の記録が消える。** |

⭐ **ADR 0042 / 0045 は「宛先自体が時点付きの記録」の例である。** ⛔ **主張も宛先も正しいのに直すと壊れる。**

### 3. ⭐ **partial index の件は、正規の置き場を ADR 0004 に集める**

ADR 0217 決定2 の形。逐語と3箇所のずれの判定は ADR 0004 の追記に置き、
`docs/memory-model.md` と `docs/recall.md` からはそこを指す。⟹ **次に直す場所が1つで済む。**

### 4. 🔴 **掃きの第一級の対象を「外部の挙動」と名指しする**

**発見1 がそのまま規律になる。** ⭐ **これから書くとき、
「PostgreSQL は」「npm は」「GitHub は」「この外部ライブラリは」で始まる断定は、
自分の実測と同じだけ名乗りを要求すること。**
⛔ **「よく知られている」は名乗りではない。** ⭐ **公式ドキュメントの URL か、`【受・未検証】` のどちらかを書く。**

### 5. 🔴 **「引用は名乗りを強められない」を規律として残す**

**発見2 がそのまま規律になる。** ⭐ **他所を引くとき、付けてよいラベルは「引いた先が持っていたラベル以下」である。**
⛔ **`【読んで確かめた】` と書くときは、「何を」確かめたのかを書くこと**——
**「そう書いてあることを読んだ」のか「その事象を自分で確かめた」のかは、別物である。**

## 確かめていないこと

- 🔴 **「候補として精査した171件」は範囲どうしで比較できない。**
  **0091–0135 は 13,232行から4件、0039–0048 は 1,432行から38件**——**行あたりで100倍以上開いている。**
  ⟹ ⛔ **候補件数は「未裏づけの密度」の指標ではない。拾い手の判断に強く依る。**
  ⭐ **【現物】で揃っているのは母集合（208本 / 59,554行）と、範囲ごとの本数・行数だけである。**
  ⚠ **とりわけ 0091–0135 は候補が著しく少なく、取りこぼしが在り得る。**
- ⛔ **「残った17件」は下限であって、上限ではない。**
- ⛔ **名乗り（ブラケット）が付いた主張の *中身* が事実と一致するかは、再導出していない。**
  **ラベルが在ることをもって落とした**（68件）。⟹ **「名乗っているが内容が違う」形は、この掃きをすり抜ける。**
- ⛔ **言い換えによる複製は検出できていない**（ADR 0217 と同じ限界）。突き合わせは**指紋の字面一致**に依る。
- ⛔ **残った17件の *真偽* は検証していない。** ⭐ **見たのは根拠の有無だけである。**
- ⛔ **`superseded` / `deprecated` の ADR を別扱いする用意はしていたが、母集合208本に該当は1本も無かった。**
  **【実測】** `- **状態**:` 行を持つのは **206本**で、そのうち `superseded` / `deprecated` / 「廃止」/「置き換」を
  含むものは **0本**（残りは「採用」197本 +「採用 (2026-09-17)」等、および「提案」1本・「未決」1本）。
  ⚠ **残り2本（ADR 0019 / ADR 0099）は `- **状態**:` 行そのものを持たない。**
  ⚠ **本文に "superseded" を含む ADR は41本在るが、それは mnemora の記憶の状態名（`superseded`）であって
  ADR の状態ではない。** ⛔ **grep の字面でこれを数えないこと。**
- 🔴 **本 ADR を書く作業自体が、同じ穴を踏んだ。**
  書き手は委譲文に「**ADR 0093 は【実測】【CI実測】【現物】【受】の4種を冒頭で定義している**」と書いたが、
  **裏を取らずに書いた。** 委譲先が現物を読み、**この ADR にブラケット記法は1つも無い**
  （「現物を読んで確認した」等の**見出し**での書き分けのみ）と差し戻してきた。
  ⟹ ⭐ **「外から受け取った知識を、名乗らずに断定する」形は、その形を掃いている最中にも出た。**
  ⛔ **これは発見1 が「他人の癖」ではないことを示している。**

- ⚠ **8つの範囲を読んだのは委譲先である（【現物・委】）。** 書き手が**自分で当て直したのは**、
  母集合の本数・行数（全範囲）、⭐ **残った17件すべての逐語**、および**発見2・3・4 の根拠**
  （`docs/release-v1.md` の逐語、ADR 0060 が実測した範囲、`1cf6a60` が3ファイルを同時に触っていること）である。
  🔴 **⛔ 落とした154件の判定は【現物・委】のままである——書き手は1件も当て直していない。**
  ⟹ ⚠ **「落とした」側に誤りが在れば、残るべきものが落ちている。** ⭐ **この掃きで最も弱いのはここである。**
