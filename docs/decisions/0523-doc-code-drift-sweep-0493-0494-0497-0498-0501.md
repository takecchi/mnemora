- **文脈**: 5つの PR の本体の変更は、次のとおり。
  - 0498: `createBullmqTickDriver` が `everyMs`・`jobName` を構築時に検査する（`Error`）。provider の数値オプション（`OpenAIEmbeddingProvider.dimensions`・`AnthropicLLMProvider.maxTokens`・`LocalEmbeddingProvider.dimensions`/`numThreads`・`OpenAILLMProvider.temperature`）を構築時に検査する（型違いは `TypeError`、数として不正は `RangeError`）。
  - 0497: `recall()` が `TokenCounter.count()` の戻りの `tokens` を検査し、有限で 0 以上の number でなければ `RangeError`。
  - 0501: 文書の負債3件（`--help` の環境変数・ANALYZE の書き込み数えがプロセスごとであること・`reinforce` の purged の記述）。

  この振る舞いを書いている文書・TSDoc に古い所が無いかを見た。対象外: `docs/migration-v1.md`・CHANGELOG・既存の `docs/decisions/*`・`docs/north-star.md`。
