## 経緯【実測】

### 今の約束

ADR 0244 決定1（3文書が中核以外の全メソッド名を並べる）は、ADR 0633 決定3・4（#1736）で覆った。層の正本は `runtime.ts` の各メソッドの doc コメントの `層:` 行で、その有無は別の歯（`runtime-method-layer-line.test.mjs`）が見る。`runtime-method-doc-correspondence.test.mjs` に残る約束は次の3つで、ADR 0244 決定2〜7は覆っていない。

- 中核5動詞の literal が `docs/vision.md` に `` `動詞` `` の形で、「中核の5動詞」の見出しとともに実在する。
- `export interface Runtime` から名前の集合を数え直せる（中核5動詞を含む・下限10。`name?(`・`name?<` も拾う）。
- 3文書が1000文字以上ある。

## 決定

1. **穴は1つ。** 抽出が緩む方向に壊れても、本体の `it`（中核5動詞を含む・10個以上）は緑のまま通る。固定の fixture による陰性対照を `runtime-method-doc-correspondence.test.mjs` に1本足した（doc コメント内の `name(`・プロパティ・メソッドの引数の行・4スペース・タブの行は拾わない）。
2. 約束より強いことは縛っていない。足した歯は「行頭2スペースのメソッド宣言だけ」という、抽出の既存の規則を固定するだけである。
3. 試験を書き換えて当てる変異は、コメントに同じ文字列があると、コメントのほうに当たって何も変えない。正規表現の変異は `methodRe = ` の行を狙った（最初は docblock 側に当たり緑だったので気づいた）。

## 確かめていないこと

- `m` ではなく `g` フラグを外す変異（`exec` が終わらない）は、試験が止まるだけなので当てていない。
- `runtime-method-layer-line.test.mjs`（`層:` 行の歯）には当てていない。担当の歯が別である。
- `Runtime` 以外の interface に同じ抽出が無いかは見ていない（ADR 0244 と同じ）。
