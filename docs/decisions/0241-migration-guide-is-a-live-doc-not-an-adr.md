## 問い

**`docs/migration-v1.md` の記述が誤っていたとき、本文を直すのか、本文を残して訂正を積むのか。**

【現物】この repo は **ADR について**、逐語こう定めている（`docs/decisions/README.md`）:

> **⛔ 採用済み ADR の本文は書き換えない。訂正が要るなら、その場に追記する。**

🔴 **問題は、この作法が `docs/migration-v1.md` にも当てられてきたことである。**
【現物】PR #528（`e89ae2f`）は、同文書の「破壊的変更（v0.2.0 → v1.0.0）」節に引用ブロックの
訂正を積み、逐語で「⛔ **下の本文は書き換えていない**（書かれた時点の記録である）」と宣言した。

【実測】その結果、[Issue #532](https://github.com/takecchi/mnemora/issues/532) の時点で
**同じ文書の中に、同じ問い（「この変更は出荷済みか」）に対する食い違う答えが同時に載っていた**——
本文が「未リリース・3件」、訂正ブロックが「8件・うち6件は出荷済み」、そして**その訂正自身も誤り**で、
正しくは 4件だった。⟹ **読む人は、どれを信じるかを自分で判断させられる。**

## 🔴 決定

### 決定1. **`docs/migration-v1.md` は生きた文書として扱う。誤った記述は本文を直す。**

⛔ **ADR 流の「本文を書き換えず訂正を積む」作法は、この文書には当てない。**

### 決定2. **訂正の経緯は、文書の冒頭の1箇所に畳む。**

⛔ **各節に訂正ブロックを散らさない。**⛔ **訂正の上に訂正を積まない（3層目を作らない）。**
⭐ **畳むのは「何がどう違っていたか」だけであり、移行手順そのものは本文が唯一の記述になる。**

### 決定3. ⛔ **折衷を採らない。**

**「一部の節だけ本文を直し、他の節は積む」は採らない。**
⟹ **同じ文書の中に2つの作法が同居すると、「どこを信じてよいか」を読む人が判断することになる**
——それは積む形の最悪の側だけを残す。

### 決定4. ⛔ **この決定の射程は `docs/migration-v1.md` である。**

**`docs/decisions/` 配下（ADR 本体）の作法は1バイトも変えない。**
【現物】同じ日に [ADR 0230](./0230-restore-superseded-recovery-path.md) へ入れた「訂正3」は、
**本文も訂正1・訂正2 も書き換えず追記する**形をそのまま踏んでいる。
⟹ **ADR は積む。生きた文書は直す。線はそこに在る。**

## 根拠

### 1. ⭐ 「書き換えず追記する」は、**ADR についての則**である

【現物】`docs/decisions/README.md` の宣言は逐語「**採用済み ADR の本文は書き換えない**」であり、
**主語が ADR である。**【現物】[ADR 0223](./0223-cross-cutting-disciplines-extracted-from-the-adr-corpus.md)
がこの規律を「ADR 211本の母集合」から抽出したときも、母集合は ADR だった。
⟹ **生きた文書へ広げる根拠は、どちらにも書かれていない。**

### 2. 🔴 この repo は既に、同じ形の腐り方を ADR として記録している

【現物】[ADR 0213](./0213-live-docs-cite-adrs-by-anchor-not-line-number.md) の表題は逐語
「**行番号での引用は、この repo 自身の「ADR は書き換えず追記する」作法によって腐る**」であり、
その本文は、**自分自身に追記したことで「冒頭にブロックが増えたので、この ADR を行番号で
指している箇所はすべてずれた」**と書いている。

⚠ **ADR 0213 が直接扱っているのは行番号引用であって、追記作法そのものの射程ではない。**
⭐ **それでも同じ因果がここに当たる**——**積むたびに、読む人が最初に当たる位置が後退する。**
移行ガイドでは、後退した先に在るのが**誤った本文**である。

### 3. ⭐ 移行ガイドは「当日に読む文書」である

**`v1.0.0` を切る当日、利用者が読むのは「どう移行するか」であって「かつてどう間違っていたか」ではない。**
⟹ **経緯は残す価値があるが、手順の手前に置く価値は無い。**決定2 はその配置の判定である。

### 4. ⚠ 記録は失われない

**訂正の経緯は冒頭の履歴表に残る。**そして**書き換える前の姿は git 履歴に在る**
（`git log -p docs/migration-v1.md`）。⟹ **「本文を直すと記録が消える」は、この文書には当たらない。**
⛔ **ADR で本文を書き換えないのは「記録が消えるから」ではなく、
「間違え方それ自体が ADR の記録内容だから」である**（`docs/decisions/README.md`）
——**移行ガイドの記録内容は、間違え方ではなく移行手順である。**

## 採らなかった案

| 案 | なぜ採らなかったか |
|---|---|
| **積み続ける**（PR #528 の側） | 【実測】実際に3層目が必要になった時点で、同じ文書が同じ問いに3つの答えを持つ。**読む人が判断させられる形**であり、移行ガイドの用途と合わない |
| **折衷**（誤りの大きい節だけ本文を直し、他は積む） | **いちばん悪い。**どの節がどちらの作法かを読む人が見分けられない。決定3 |
| **移行ガイドを ADR 化する**（凍結して版ごとに新規作成） | 版が出るたびに文書が増え、**利用者が「どれを読めばよいか」を選ばされる。**⛔ 反重複規律とも衝突する |
| **何も決めない**（その都度判断） | 🔴 **今回の腐り方がまさにこれである。**PR #528 と本 PR が反対の作法を採っており、**次の担い手はまたどちらかを引く** |
