# ADR 0616: ADR 0074 の「印象」「話題」「成長」は、非目標「複雑な感情シミュレーション」に含まれない — AI 側の感情の状態は持たない

- **状態**: 採用 (2026-10)
- **日付**: 2026-10-06

**出所**: オーナーへのまとめ問い（承認キューの id 70449a95）の問3に、オーナーが2026-10-05T18:03Z に「推奨どおり」と答えた。下の「決定」1〜3 は、その問3で示した解釈である。同じ時刻に、別の問い（承認キューの id 018eb5ac）でも、オーナーは #761 の「印象」について「含まれない」を選んでいる【受】（依頼主から聞いた。承認キューは repo の外に在り、この ADR の書き手は中身を見ていない）。

**オーナーが決めたのは、この解釈だけである。**この ADR の書き手はマネージャー（mgr-3cdbd12b、クローンの委譲による）である。この ADR の構成、「決定」4 以降、「採らなかった案」「引き受けた負債」「これが覆るとしたら」は、書き手がまとめた。オーナーが決めたものではない（[ADR 0220](./0220-issue-comment-author-does-not-distinguish-owner-from-agent.md)）。

## 文脈

[ADR 0074](./0074-impression-topic-growth-what-mnemora-cannot-hold.md) は、オーナーの発言「mnemora は『印象』『話題』『成長』を持てない」を受けて、現物を当てた結果と3つの案を並べた。状態は「提案（未採用）。オーナーの判断待ち。」で、末尾の「オーナーへ差し戻す問い」に4問がある。[Issue #761](https://github.com/takecchi/mnemora/issues/761) はその4問をオーナーへ問うために立てた。

4問の1つ目は、次のとおりである（ADR 0074 から逐語）。

> 1. **「印象」は、`docs/north-star.md`「やらないこと」の「複雑な感情シミュレーション」に当たるか。**

`docs/north-star.md` の「やらないこと」はオーナーが仕様に書いた非目標で、追記も削除もオーナーの判断である（同ファイル、`docs/autonomy.md` §3「してはいけないこと」の表）。だから、この線引きはオーナーにしか引けなかった。

## 決定

1. **ADR 0074 の「印象」「話題」「成長」は、`docs/north-star.md`「やらないこと」の「複雑な感情シミュレーション」に含まれない。**（オーナー）
2. **印象は、確信度と根拠のついた推論として持つ。成長は、時間とともに変わる事実の系譜として持つ。**（オーナー）
   - 印象は、AI がユーザーについて推論した内容である。ADR 0074 §2.2 が、今の型で近いものとして `InferredProvenance` の `confidence`・`basis` を挙げている。
   - 成長は、「前はこうだった、今はこうだ」という事実の移り変わりである。ADR 0074 §2.3 が、近いものとして `supersededById` の系譜を挙げている。
   - ⚠ 「持つ」は向きであり、今の main で足りているという意味ではない。ADR 0074 §2 が「落ちるもの」として挙げた点（`confidence` が recall の返り値に出ない、確信度を後から動かせない、など）は、この ADR では直していない。それらが今の main でも当たっているかは、別に当て直す（「引き受けた負債」1）。
3. **AI 側の感情の状態（興味度・気分など）は持たない。**（オーナー）
   - ADR 0074 §2.1 (c) が引いた `interest`（「キャラの興味度 (0-100)」）のような、AI の側の主観の量はこれに当たる。mnemora はそれを記憶の欄にも、状態としても持たない。
   - 線は「誰の状態か」で引く。ユーザーについての推論（印象）は持つ。AI 自身の感情の状態は持たない。
4. **`docs/north-star.md`・`docs/vision.md` の「やらないこと」の一覧は変えない。**決定1 は一覧への追加・削除ではなく、既にある1項目の範囲についての解釈だからである。
5. **ADR 0074 の本文と状態欄は書き換えない。**ADR 0074 の4問のうち、この ADR が答えるのは問1だけである。
6. **ADR 0074 の残りの3問（問2〜4）は、決めていない。**[Issue #761](https://github.com/takecchi/mnemora/issues/761) に残っている。
   - 問2: 「成長」が指すのは `PersonaGrowthEntity` か、`PersonaEvolutionProposalEntity` か。
   - 問3: 記憶ごとの重要度を `Memory` に持たせるか。
   - 問4: 印象の帰属を「誰が、誰について」の順序対にするか。
   - ⚠ 決定2 の「成長は事実の系譜として持つ」は、問2 にどちらかで答えたものとして読まないこと。どちらのエンティティに当たるかは、まだ問いのまま残っている。
7. **この ADR は実装を含まない。**ADR 0074 の案1〜3 のどれも採っていない。

## 採らなかった案

- **ADR 0074 の状態欄を「採用」に変え、問1 の答えを本文に書き込む**: 採らなかった。残りの3問は決まっておらず、ADR 0074 は今も3つの案のどれも選んでいないからである。また、ADR 0074 は 2026-09-09 時点の現物で書かれている。答えを書き足すと、古い現物の記述と新しい判断が1つの文書に混ざる。
- **`docs/north-star.md` の「複雑な感情シミュレーション」に注記を足す**: 採らなかった。正典の書き換えはオーナーの判断である（`AGENTS.md`）。オーナーが答えたのは解釈で、正典を書き換えることまでは答えていない。
- **Issue #761 を閉じる**: 採らなかった。4問のうち3問が残っている。

## 引き受けた負債

1. **ADR 0074 の記述は 2026-09-09 時点の現物のものである。**行番号・型・振る舞いが今の main とずれている箇所が在りうる。この ADR はそれを確かめずに、ADR 0074 の節を指している。当て直しは別に行う。結果に食い違いがあっても、ADR 0074 の本文は書き換えない。
2. **ADR 0074 だけを読んだ人には、問1 がまだ開いているように見える。**ADR 0074 の本文を書き換えないためである。辿る道は、索引（`docs/decisions/README.md`）でこの ADR が隣に並ぶことと、Issue #761 から指すことだけである。
3. **「感情の状態」の範囲は、例（興味度・気分）でしか示していない。**新しい欄が「AI 側の感情の状態」に当たるかに迷ったら、決定3 の線（誰の状態か）に当てる。それでも決まらなければ、オーナーに問う。

## これが覆るとしたら

- オーナーが、印象・話題・成長のどれかを「複雑な感情シミュレーション」に含める、と答え直したとき。
- 印象や成長を実装しようとして、AI 側の感情の状態（決定3）を持たないと成り立たないことが分かったとき。その場合は実装を進めず、オーナーに問い直す。
- `docs/north-star.md` の「やらないこと」の一覧を、オーナーが書き換えたとき。
