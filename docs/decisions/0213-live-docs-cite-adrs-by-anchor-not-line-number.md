## 決定

### 1. 生きた文書は、ADR を行番号で指さない

**「生きた文書」＝ いま従う指示として読まれるもの**（`docs/**/*.md` のうち `docs/decisions/` を
除いたもの・`AGENTS.md`・`README.md`）。⟹ **引用先に実在する文字列（見出し・太字ラベル・逐語）で指す。**

```
ADR 0067「⭐ (B) の一般化 — この ADR の芯」
```

### 2. ⭐ アンカーが腐らないのは、行番号を壊しているのと**同じ規律**のおかげである

**ADR の本文は書き換えない**（ADR 0064）。⟹ **一度実在した文字列は、そこに在り続ける。**
⟹ **冒頭への追記はアンカーを1文字も動かさない。**

🔑 **同じ1つの規律が、行番号を腐らせ、アンカーを守っている。**
⟹ **だからこの移行は「問題を別の形へ移した」のではない。**

### 3. 歯は**1本だけ**置く。**生きた文書に限る**

`scripts/adr-citation-lib.mjs`（純関数）＋ `scripts/__tests__/adr-citation.test.mjs`。
ルートの `pnpm run test` に相乗りする（`identifier-probes-readme-freshness` と同じ形。
CI への配線は要らない）。

**歯: 生きた文書に、ADR への行番号引用が1件も無いこと。**

⛔ **アンカーの実在検査は、歯にしない**——測ったこと8。**構文で3つを区別できない。**
⟹ 代わりに、**この PR が入れた15種のアンカーだけ**を名指しで検算する歯を置く
（**歯ではなく移行の検算である**、とテストに明記した）。
⭐ **その一覧が腐らない理由は決定2 と同じ**——**ADR の本文は書き換えない。**

### 4. ⛔ 件数を歯に焼き込まない

**再現率は、現物ではなく静的な fixture で測る**——18件の**古い書き方**をテストの中に
リテラルで持ち、検出器が1件残らず拾うことを見る。
⛔ **「repo 全体で N 件」を assert する歯は置かない**——**ADR が1本増えるたびに落ちる。**
それは歯ではなく snapshot である。

### 5. ポインタは直す。主張は追記で訂正する

| 種類 | 扱い | 理由 |
|---|---|---|
| **ポインタ**（宛先の書き方） | **その場で直す** | **住所であって、「当時こう判断した」という記録ではない。**古い住所を残す意味が無い |
| **主張**（測ったこと7 の `:140` のような） | **消さず、追記で訂正する** | **記録である。**この文書の作法（ADR 0064） |

### 6. ADR 本体（`docs/decisions/*.md`）の行番号引用は直さない

**【受】**A の41件のうち **20件は ADR が ADR を行番号で指している。**
⛔ **直さない**——**ADR は当時の記録であり、本文を書き換えない**（ADR 0064）。
⟹ **歯の判定対象からも外す。**⚠ **検出器そのものは ADR も走査する**
——**外すのは判定の段であって、検出の段ではない。**方針を変えるときに検出器を書き直さずに済む。

### 7. ADR 0209 の本文は書き換えない。前方参照だけを足す

測ったこと6 の訂正はこの ADR に置き、0209 へ足すのは冒頭の1ブロックだけである
（ADR 0209 が 0207 に対して採ったのと同じ形。**【実測】**その形が10行の追加・0行の削除であることを確かめてある）。

## 採らなかった案

- **762件を全部直す。**⛔ 採らない——**C（ソース600件）は ADR が「当時こうだった」と
  記録しているものであり、いまの行へ追いかけて直すのは記録の書き換えである。**
- **アンカーの実在検査を歯にする**（repo 全体でも、生きた文書3本に絞っても）。
  ⛔ 採らない——測ったこと8。**repo 全体で 605件中205件、3本に絞っても 61件中14件が
  「実在しない」と出る。**⟹ **それらは壊れているのではなく、あだ名か逐語引用である。**
  ⚠ **あだ名を禁じる案も採らない**——**`「無いには種類がある」` だけで18箇所定着しており、
