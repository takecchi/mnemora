# ADR 0672: 09/25 にマージされた PR の確かめ直しで見つかったすり抜けに歯を足す（Issue #1775）

- **状態**: 採用 (2026-10)
- **日付**: 2026-10-07

**これはクローン（miku）の判断で、オーナーの判断ではない**（[ADR 0220](./0220-issue-comment-author-does-not-distinguish-owner-from-agent.md)）。出所は Issue [#1775](https://github.com/takecchi/mnemora/issues/1775)。
出所の区別: 【現物】は読んだコード、【実測】は手元で走らせた結果、【受】は自分で測らずに受け取ったもの、【判断】は担い手の判定。
これは試験だけの変更で、実装・TSDoc・migration・fixture・CHANGELOG・公開の適合テスト（`*-conformance.ts`）は触らない（[ADR 0665](./0665-merged-0924-recheck-teeth.md) と同じ）。

## 経緯

2026-09-25（UTC）にマージされた50本の PR に、足りない側とやりすぎた側の変異を当てた記録が #1775 のコメントにある。【受】すり抜けた変異のうち、約束が PR 本文・公開の doc・ADR に書いてあるものに歯を足す。**この ADR は、Issue #1775 の「区切りその1」の案（A・D 群）と、各 PR のコメントの「塞ぐ歯の案」（B・C 群）から起こした。**

**数え方**: 表の1行は、1つのすり抜けた変異（同じ歯が複数の実装を縛るときは、実装ごとの変異を1行にまとめて「各1」と書いた）。歯は全部で85行、対象は #1775 の50本のうち下の表の PR。

## 決定【判断】

1. **実装は変えない。**公開の適合テストにも足さない。歯は、各パッケージに固有のテストに置く。
2. 歯の範囲は、約束が PR 本文・公開の doc・ADR に書いてあるものとする。前任が「約束の外・要判断」と付けた案でも、doc・ADR に書いてある約束なら入れる。
3. 約束が後の ADR で狭まっているときは、いまの約束に当てる。#736 は ADR 0474（べき等性の例外の入力には当てない）、#745 は ADR 0377・0473 で狭まり 0378・0381 で広がった後の約束に当てる。

## 約束が後の ADR で狭まったものの扱い【判断】

- **#736（claimKey の第1段）**: ADR 0474 が「正規化のべき等性」に、大文字と結合文字が混ざる一部の入力だけ例外を認めた。歯は、例外の入力には当てない（例外の入力を使う歯は足していない）。足した歯は、片方だけ NULL の行の読み方と索引の形で、ADR 0474 の例外とは交わらない。
- **#745（claimKey の contested 検出）**: ADR 0377・0473 で「同じ観測の兄弟を除く」が狭まり、0378・0381 で広がった。歯は、狭まり・広がった後のいまの約束（`detectContested` の opt-in、観測を持たない記憶は兄弟にならない）に当てた。
- 今後、採用済みの ADR で約束が明示的に狭まっているときは、止めずに同じ扱いにする。止めて聞くのは、狭まったのに書いた ADR・doc が見当たらないときと、狭まった理由が「取り下げ」で約束そのものが無くなっているときの2つだけ（Issue #1775 のクローンの判断）。

## 確かめ方【実測】

- 足した歯は、すべて、いまの main（このブランチの土台）で緑であることを確かめた。
- 表の「変異での赤」は、元のすり抜けの変異（または同じ約束を破る変異。#745・#722・#782 の言い換えは各行に書いた）を `cp` で当てた状態で、足した歯が落ちたこと。変異ごとに、元のファイルへ `cp` で戻し、`cmp` が一致することを確かめた。
- Postgres は自分専用のクラスタ（`C.UTF-8`・UTF8・pgvector）で走らせた。Redis は無いので、#746 の歯は `bullmq` をモックにした単体に置いた（Redis の歯は走らせていない）。
- migration を当てる変異（#736 の CHECK・索引の3本）は、globalSetup が migrate 済みの base DB を再利用するので、DB を作り直してから走らせた。#717 の backfill の変異は、歯が fixture から DB を作るので作り直し不要だった。
- 変異を当てた歯が、いまの main で空振りしていないことは、歯の中に陽性対照（無い・拒むを見る歯には、在る・通る側）を置いて確かめた。
