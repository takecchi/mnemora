## 決めたこと（骨）

**取りこぼしがゼロにならないと分かっている道具に「これが全部です」と名乗らせない。⟹ 判定（exit 非0）ではなく一覧として出し、取りこぼす側と余計に拾う側の実例を出力そのものに焼く。**
⟹ 入口に在るのは「人が書く報告」の版（`AGENTS.md`「確かめていないことは「確かめていない」と書く」／`docs/autonomy.md` §5）。**宛先を *道具の出力* へ広げる。**
