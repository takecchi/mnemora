# ADR 0024: 実装の無い `exactCounts` を、「予約」と書き残さずに削除する

- **状態**: 採用 (2026-09)

- **文脈**:

  `RecallQuery` に `exactCounts?: boolean` という欄が在った。docstring は
  「目次帯（第3階）の厳密カウントを要求するか。**既定は近似許可（false）**」と書いていた。

  **⚠ しかし、この欄を読むコードはリポジトリのどこにも無かった**
  （`grep` の結果は型定義と zod スキーマの2行だけ）。
  `MemoryStore.aggregateScope` は**常に厳密集計**であり、`countKind` は全箇所で
  リテラル `"exact"` を返す。近似の経路は存在しない。

  **⟹ 二重に嘘をついていた。**
  1. 「既定は近似許可」——近似の経路が無いので、既定も何も無い。
  2. 「厳密カウントを要求する」——**値を受け取って黙って無視していた。**
     呼び出し側は「頼んだ」と思える。**静かに失敗する形そのものである。**

  これは [ADR 0008](./0008-absence-taxonomy.md) の芯——**推定値を実測値の顔で出さない**
  ——と同じ病である。0008 は「値」について言っているが、ここでは**摘み**が
  名乗りどおりに働いていなかった。

- **決定**:

  **`RecallQuery.exactCounts` を削除する**（interface と zod スキーマの両方から）。
  「予約・未実装」と書き残す形は**採らない。**

- **なぜ「予約」と書き残さずに消すのか（オーナー判断）**:

  - **消せば、呼び出し側は型で落ちる。**うるさいが、**気づける。**
    まだ publish していないので、**いま消すのがいちばん安い。**
  - 「予約」と書けば、**書いてあるだけで実行されない。**約束が残り、誰も果たさない。

  ⟹ **「あとでやる」を型に書くのは、本文だけに書くのと同じである。**
  （この repo は同じ失敗を一度している——[ADR 0019 §5](./0019-real-openai-measurement-cost.md)
  が「記憶の84%が埋め込まれていない」と実測して**記録したが直さなかった**結果、
  北極星の主測定が誤ったまま残った。直したのは
  [ADR 0021](./0021-drain-embed-ticks-in-ingest.md) である。）

- **検討した代替案**:

  - **「予約・未実装」と docstring に書いて残す**: 却下（上記）。
  - **`exactCounts` を実際に実装する（近似経路を作る）**: 却下、**いまは**。
    **近似が要るかどうかを、まだ誰も測っていない。**
    `docs/roadmap.md` §5.6（テナントあたりの想定記憶数）も未決である。
    **測る前に欄を足すと、[ADR 0011](./0011-no-window-count-in-ann-stage.md) の
    `count(*) OVER ()` と同じ事故になる**——区別を表す欄が、名乗りどおりの値を
    持たないまま置かれる。
  - **`CountKind` に `'estimated'` を足す**: 却下、**いまは**。同上。
    なお `CountKind` は `'exact' | 'lower_bound' | 'unknown'` であり、
    `'estimated'` という値は**存在しない**（ADR 0008 は「閉じた集合として設計していない」
    と書いており、足すこと自体は禁じていない——ただし**測ってからである**）。

- **この決定が前提にしている、まだ無いもの**:

  **`aggregateScope` の費用を 10k / 100k / 1M の3点で測る**こと。
  1点で決めず範囲で測るのは、`docs/roadmap.md` §5.6 の答えを待たずに
  **「どこから近似が要るか」を曲線として出す**ためである
  ——§5.6 がどちらに決まっても、その答えが既に手元に在る形にする。
  この測定は [ADR 0023](./0023-subject-filter-in-ann-stage.md) が残した穴
  （subject で絞ると HNSW が捨てられ、埋め込み側が `Seq Scan` になる。大規模で未測定）
  にも同時に答える。**1つの測定で2つの穴が埋まる。**

- **歯について（正直に書く）**:

  **この変更に対して新しい歯は足していない。**欄を消すことの安全性を守るのは
  **型検査そのもの**であり（参照していた箇所があれば `typecheck` が落ちる。
  実際には参照は0件だった）、振る舞いは1ミリも変わらないため、
  **意味のある歯を書きようがない。**書けないものを書いたふりをしない。

  なお「`aggregateScope` の群カウントが `countKind: 'exact'` を返す」ことは、
  `packages/core/src/__tests__/recall-pipeline.test.ts` と
  `packages/postgres/src/__tests__/recall.postgres.test.ts` の既存の歯が既に押さえている
  ——**近似経路を足すときに、この歯が「名乗りが変わった」ことを教える。**

- **これが覆るとしたら**:

  上記の測定で「この規模から厳密集計は割に合わない」と分かったとき。
  そのときは近似経路と、それを正直に名乗る `CountKind` の値を**同時に**入れる
  ——**片方だけ入れない。**
