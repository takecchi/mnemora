# ADR 0239: 生きた文書のソース行番号引用は、**凍結記録と生きた散文を機械で見分けられない** — 射程を広げない（Issue #512）

- **日付**: 2026-09-18

**⚠ 各主張の出所を分ける**（ADR 0132 / 0137 / 0179 / 0212 / 0228 / 0234 の体裁を踏む）。

- **【現物】** — この repo のコード・文書を書き手が読んで確かめた。
- **【実測】** — この書き手が自分の手で `git` / `node` を走らせて確かめた。
- **【受】** — 報告として受け取り、再導出していない（出所を明記する）。

**測定条件**: 断りの無い【実測】は `origin/main` = `06a8f88` の木で、2026-09-18 に行った。

## 問い

[Issue #512](https://github.com/takecchi/mnemora/issues/512) は、**生きた文書（`docs/**` から `docs/decisions/` を除いたもの・`AGENTS.md`・`README.md`）がソースファイルを行番号で指している箇所が 122ある**ことを棚卸しし、⛔ **直すかどうかは判断として残した。**

そして自分で「最初に答えるべき問い」を立てている【現物・逐語】:

> 🔴 **これは [#505 の決定9](https://github.com/takecchi/mnemora/issues/505)…で覆えるか。**

その決定9 の成文化は [ADR 0234](./0234-bake-no-numbers-into-tools-and-artifacts.md)（PR #520）で `AGENTS.md` に着地した。⟹ **この ADR は、その問いに答える。**

## 🔴 決定

### 決定1. **既存122件へ射程を広げない**

**`AGENTS.md`「⚠ 数を、道具と生成物に焼き込まない」の射程を、生きた文書のソース行番号引用まで広げることはしない。**

**理由は「難しいから」ではない。⭐ 3つの形を実際に測って、3つとも落ちたからである**（決定2）。

### 決定2. ⭐ **落とした3つの形と、その数字**

⛔ **「検討した結果できないと判断した」ではない。**次を測った。

**母集合**: `docs/roadmap.md` の**112件**【実測】。#512 が数えた122件のうち**支配的な集団**である（残りは `docs/release-v1.md` 9・`docs/conformance.md` 4 ほか）。

**信号**: 凍結宣言（`書き換えない` / `書き換えていない` / `書き換えずに残す` / `1バイトも書き換え` / `当時の記録` / `判定した時点の記録` ほか）と、**読んだ時点の名乗り**（`main = <sha>` / `時点である` / `時点の位置` / `読んだのは`）。

| # | 形 | 凍結と判定 | 直す候補 | 🔴 落ちた理由 |
|---:|---|---:|---:|---|
| **1** | 引用を含む**最も近い見出し**の範囲に信号が在るか | 93 | **19** | **偽陽性。**19件のうち **12件が §7.10（758-837行）の子節**に在り、⭐ **凍結宣言は §7.10 の*前文*に在る**（逐語「⛔ **見出しと以下の本文は、判定した時点の記録として書き換えない。**」）⟹ **子節自身の範囲には信号が無いので「生きている」と誤判定する** |
| **2** | **祖先のどの見出しの範囲**にでも信号が在るか | **112** | **0** | **無意味。**§7（`## 7. v1.0 までの日別予定`、700行超）が信号を含むため、**その下にある全部を飲み込む** |
| **3** | 既存は据え置き、**diff で新規追加だけを見る** | — | — | **偽陽性率 2/4 = 50%**（下記） |

#### 形3 の実測 —— 直近60 commit で発火4件、うち**2件が偽陽性**

| commit | 何を足したか | 判定 |
|---|---|---|
| `5f83c2b` | 逐語「**§7.11 の3件は数字を直さず鮮度を名乗らせる**」 | 🔴 **偽陽性**（意図した焼き込み） |
| `44ea1e8` | **PR #481（Revert）本体** —— 凍結記録を復元した | 🔴 **偽陽性** |
| `a7b7ff1` | 生きた散文に `recall-runtime.ts:805` / `strategies/scoring.ts:272` 等 | ⭕ 真陽性 |
| `d5e6e38` | `docs/release-v1.md` に `publish.yml:76-102` / `publish.yml:225` | ⭕ 真陽性 |

⟹ 🔴 **[ADR 0223](./0223-cross-cutting-disciplines-extracted-from-the-adr-corpus.md) 決定3（「門にしてよいのは、偽陽性率に上限を置けると実測できたものだけ」）に、はっきり掛かる。**
⚠ **そして標本が4件しかない。**⟹ **上限を置けない**（同 決定6「『出なかった』を何回積んでも、事象が起きないことの証明にはならない」の裏返しで、**4件から率の上限は主張できない**）。

### 決定3. ⭐ **落ちたのは原理ではない。足りないのは機械可判定性である**

**[ADR 0234](./0234-bake-no-numbers-into-tools-and-artifacts.md) が置いた見分ける問いは、文書側にも正しく当たる**【現物・逐語】:

> ⭐ **見分ける問いは1つ**: **その数は、どこか別の場所に在る正本の*写し*か。それとも、それ自体が*測った記録*か。** ⟹ **写しなら指す。記録なら残す。**

⟹ ⭐ **§7.4 の行番号は「`main = 9fcd47c` で読んだ」という*測った記録*であり、生きた散文中の行番号は*写し*である。**⟹ **原理としては、この2つは正しく分かれる。**

🔴 ⟹ **だから「射程を広げない」は、原理を否定していない。⛔ 人がこの問いを当てることは、いまも要求されている。**落としたのは**機械にこの問いを当てさせる形**だけである。

### 決定4. 🔴 **凍結宣言の射程は、見出しの入れ子で表現できない**

これが決定2 の形1・形2 が両方落ちた**共通の原因**である。

- **【受】PR #481 の実測**: 「`docs/roadmap.md` §7（442行〜末尾）には『1バイトも書き換えていない』『書き換えない』『書き換えずに残す』の宣言が **14箇所**ある」。
- ⟹ **同じ §7 の中に、凍結記録と生きた散文が混在している。**
- ⟹ **宣言はある節の前文に書かれ、その子節すべてに効く。**⛔ **だが「どこまで効くか」はどこにも書かれていない。**

⟹ ⭐ **節の境界と凍結の境界が一致していない。**⛔ **一致させる規約は無く、この ADR でも作らない**（既存の生きた文書を全部書き直すことになるため）。

### 決定5. 🔴🔴 **線が完璧に引けても防げない失敗が、現に在る**

⚠ **これは Issue #512 が書いていない。**PR #481 の本文を読んで見つけた【現物】。

#479 が §7.4 の6件をアンカーへ置き換えたとき、**§7 の別の箇所（`docs/roadmap.md` の「その後の節」）が、置き換えられた行番号の*文字列そのもの*を参照していた**。PR #481 の逐語:

> ⟹ ⭐ **この文書は既に「腐った数字を直す」のではなく「鮮度を名乗らせる」形を採っていた。** #479 が行番号をアンカーへ置き換えたことで、**603行の参照先が宙に浮いた**——「上の節が引く `recall.ts:1104`」と書いてあるのに、上の節にその文字列が無くなった。

⟹ 🔴 **引用文字列それ自体が、別の箇所からの被参照物になっている。**
⟹ ⭐ **「この引用は凍結記録か」をどれだけ正確に判定しても、この失敗は防げない。**判定が正しくても、**置換した瞬間に他所の参照が壊れる**からである。

⟹ ⛔ **線を作る方針そのものの限界である。**決定2 が測った3つの形のどれを直しても、ここは残る。

### 決定6. ⭐ **代替として「門ではなく候補の一覧」なら作れる。⛔ ただし今回は作らない**

[ADR 0223](./0223-cross-cutting-disciplines-extracted-from-the-adr-corpus.md) 決定5 が、**名乗れないものを名乗れないときの代替**を明示している【逐語】:

> **取りこぼしがゼロにならないと分かっている道具に、『これが全部です』と名乗らせない。**⟹ **判定（exit非0）ではなく一覧として出し、取りこぼす側と余計に拾う側の実例を、出力そのものに焼く。**

⟹ ⭐ **決定2 の形3（diff で新規追加を見る）は、門にはできないが *候補の一覧* としてなら成立する**（偽陽性 2件の実例を出力に焼けばよい。`scripts/release-candidates.mjs` が採っているのと同じ形）。

⛔ **だが、この ADR では作らない。理由2つ:**

1. **v1.0.0 を止めない**（#512 自身が「どれも v1.0.0 を止めない」と書いている前段の #471 と同じ性質）。
2. 🔴 **いま要るという根拠が無い。**【実測】発火は**60 commit で4件**であり、**うち2件は意図した焼き込み**である。⟹ **人が月に数回見る量であり、道具が無いことで何かが落ちている証拠が無い。**

⟹ ⭐ **「作れる」という事実だけを、ここに残す。**次に必要になった人は、決定2 の形3 から始めればよい。

## 採らなかった案

| 案 | ⛔ 落とした理由 |
|---|---|
| **122件を人手で振り分けて直す**（#512 の案 (う)相当） | 🔴 **一度それで失敗している。**PR #479 → **PR #481 で Revert。**⟹ **同じ形をもう一度やるなら「失敗したときと何が変わったか」を言えなければならないが、何も変わっていない**（線が無いまま人が振り分ける形は同じ） |
| **節の境界と凍結の境界を一致させる規約を作る** | ⛔ 既存の生きた文書を全部書き直すことになる。⚠ そして `docs/roadmap.md` §7 は**それ自体が凍結記録の集合**であり、**書き直しが規約違反になる** |
| **凍結宣言に機械可読な印（HTML コメント等）を足す** | ⚠ **印を足す作業そのものが、122件の振り分けと同じ判断を要求する。**⟹ 問題を移しただけである |
| **ADR 0234 の射程を「文書」まで広げる文だけ書き、歯は作らない** | ⚠ 一見成立するが、⛔ **広げた射程は既存122件を違反にする。**⟹ **直せない違反を作る**——[ADR 0213](./0213-live-docs-cite-adrs-by-anchor-not-line-number.md) が「762件を全部直す」を落としたのと同じ理由 |

## 引き受けた負債

- 🔴 **122件の行番号引用は、腐り続ける。**⛔ **これを「直さないと決めた」と読まないこと。決めたのは「直す対象を安全に選ぶ方法が無い」である。**⚠ そして腐りは**静かに**進む——行がずれても文章は読めるので、指し先が別の場所になったことに誰も気づかない。
- **腐り率の現在値を測っていない。**[ADR 0213](./0213-live-docs-cite-adrs-by-anchor-not-line-number.md) が測った 11%（`docs/release-v1.md` 63件中7件）は**別の母集合・別の時点**である。
- **決定5 の失敗（引用文字列が被参照物）が、いま他に何件在るかを数えていない。**⟹ 見つかっているのは PR #481 の1件だけである。

## これが覆るとしたら

- **凍結宣言の射程が、機械可読な形で表現されるようになったとき**（節の境界と一致させる規約ができる、または印が入る）。⟹ 決定2 の形1・形2 が成立しうる。
- **発火の頻度が上がったとき。**⟹ 決定6 の「いま要るという根拠が無い」が崩れる。**60 commit で4件**という数字が、この決定の前提である。
- **決定5 の形（引用文字列が被参照物）が、実は1件しか無いと確かめられたとき。**⟹ 決定5 の重みが下がる。⛔ **いまは数えていない。**

## ⚠ 確かめていないこと

- **決定2 の測定は `docs/roadmap.md` の112件に対してのみ行った。**⛔ 残り10件（`docs/release-v1.md` 9・`docs/conformance.md` 4 ほか。⚠ #512 の内訳と合計が合わないのは数え方の差である）には当てていない。⟹ **形1・形2 が他のファイルでも落ちるかは測っていない。**
- **信号の正規表現が網羅であることは示していない**（ADR 0223 決定4 の反例が自分に当たる）。凍結宣言の言い換えを取りこぼしている可能性は消していない。
- **形3 の標本は直近60 commit である。**⛔ **repo 全履歴では測っていない。**
- ⭐ **決定2 の形1 の「12件が §7.10 の子節」は、最初 *手で数えて16件* と書き、機械で数え直して **12件** に訂正したものである**【実測】。⟹ **この ADR 自身が、焼き込んだ数を一度間違えた。**（[ADR 0234](./0234-bake-no-numbers-into-tools-and-artifacts.md) の節が言っているとおりである。）
